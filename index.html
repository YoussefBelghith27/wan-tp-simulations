Les TP WAN, à rejouer commande par commande

Dix travaux pratiques, du backbone MPLS au Frame Relay. Chaque simulation vous fait taper les commandes IOS dans la console, quatre d'entre elles vous font aussi analyser les trames dans Wireshark, et chaque compte rendu détaille la configuration, les vérifications et les réponses aux questions.

Voir les TP
Chaque routeur est un TP : cliquez pour y aller.

Utiliser une simulation

  1. Ouvrez un TP avec Lancer la simulation. Le sous-titre en haut de l'écran explique chaque étape.
  2. Quand le cadre vert apparaît sur l'invite, tapez la commande IOS demandée puis appuyez sur Entrée. Les abréviations courantes sont acceptées (conf t, sh ip route…).
  3. Dans les écrans Wireshark, tapez le filtre d'affichage demandé dans la barre de filtre, puis cliquez sur la trame ou l'en-tête entouré en orange pour le déplier.
  4. Le mode Démo tape les commandes à votre place. À la fin, le score indique les commandes réussies du premier coup.

Le TP1 partie 1 utilise les captures réelles de la manipulation sous GNS3. Pour les autres TP, les écrans de console et de Wireshark sont reconstitués à partir des configurations des énoncés : ce sont des résultats attendus, signalés comme tels dans chaque simulation et chaque compte rendu. Les fichiers ActivePresenter (.approj) sont aussi disponibles pour être modifiés.
